# Ручная проверка импорта

Автоматические тесты и проверки движков не подтверждают работу GUI каждого приложения.
Каждый пункт ниже пока ожидает ручного прогона. Для проверки использовать выделенное
подключение и собственные устройства/учётные записи; не публиковать действующие ключи.

Для каждой пары записать версию приложения и ОС, проверить установку, импорт,
подключение, открытие сайта через VPN, получение ссылки/QR либо файла, смену приложения
и повторное открытие сохранённого профиля. Проверять только поддерживаемые профиль
и транспорт; при несовместимости должна появляться причина и рабочая альтернатива.
Отдельно проверить, что сроков и квот в боте нет, а удаление устройства сохраняет ключ.
